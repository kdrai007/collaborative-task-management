# Design Conventions Rule

Always follow the design conventions specified in the `DESIGN.md` file located in the project root.

Before writing any code, review the DESIGN.md file to understand:
- UI/UX standards
- Component structure
- Styling patterns
- Design system guidelines
- Color schemes and typography
- Spacing and layout rules

When implementing features:
1. First read DESIGN.md to understand the design requirements
2. Apply the conventions consistently across all code
3. If there's any conflict between standard practices and DESIGN.md, prioritize DESIGN.md
4. Ask for clarification if design conventions are unclear

The design file is authoritative for all UI/visual decisions in this project.
